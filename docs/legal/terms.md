# Правила сервиса StaffSwipe

1. **Запрещены:** дискриминация, оскорбления, спам, публикация ложных смен,
   попытки обойти оплату комиссии, сбор персональных данных вне Сервиса,
   требование денег с соискателя за трудоустройство.
2. **Заведение обязано** указывать достоверные условия смены: ставку, время,
   адрес, способ оплаты. Условия смены, по которой уже есть отклик, менять
   нельзя — человек согласился именно на них.
3. **Соискатель обязан** соблюдать договорённости и приходить на подтверждённые
   смены. Систематические неявки снижают надёжность профиля.
4. **Отметка о приходе.** Код прихода называет заведение работнику на месте;
   передавать код заранее или отмечаться не выходя на смену — нарушение.
5. **Один аккаунт на человека и на заведение.** Аккаунт привязан к Telegram;
   при потере доступа обратитесь в поддержку.
6. **Нарушения** ведут к предупреждению, а при повторении — к блокировке
   аккаунта. При блокировке неизрасходованный остаток денежного баланса
   возвращается по обращению за вычетом начисленной комиссии.
