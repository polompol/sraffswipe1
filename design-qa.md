| Находка | Исправление | Проверка |

| Одно нажатие звезды сразу отправляло отзыв | Выбор рейтинга → комментарий → «Отправить отзыв» | Тест компонента и браузерный выбор 5 звёзд без отправки. |

| Штамп поверх свайпа расходился с пожеланием «без печати» | Удалён штамп, оставлены движение и тактильный отклик | TypeScript, Vitest; обычные состояния колоды просмотрены. |

## Взаимодействие и ограничения среды

Пройдено: демо-регистрация сотрудника с именем/ролью/городом, лента, листание фото, открытие и закрытие подробностей, сохранение, переходы в смены/профиль/чат, фильтры текущих смен и истории, выбор оценки без отправки. Создание и предпросмотр смены, обе роли, чат/WS, код, расчёт, PDF и перекрывающие панели проверены существующими E2E с реальным тестовым API.

При сравнении смена страницы референса создаёт запись общей истории iframe: для возврата из чата пришлось сначала вернуться через запись референса. Это особенность временной страницы сравнения; она не поставляется с приложением.

Финальная ручная попытка выйти из демо-профиля открыла браузерное `window.confirm`, после чего управляющий браузером CDP стал отвечать таймаутом. Дополнительные ручные снимки мастера работодателя и заключительное чтение консоли в этой сессии не завершены. До этого просмотренные экраны работали; ранняя консоль содержала сообщения расширения браузера. Отсутствие ошибок финальной консоли не заявляется. Проверка мастера подтверждена E2E, а реальный Telegram popup требует проверки на устройстве.

Автоматические результаты: backend 517 passed / 1 skipped; frontend 157 passed; E2E 43 passed. Пропуск — реальный Redis Pub/Sub без установленного `redis-server`. Временные страницы сравнения удалены из `public`, чтобы не попадать в сборку.
